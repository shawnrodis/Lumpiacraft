# Lumpiacraft

Lumpia Recipe Scaler — scale a Filipino lumpia recipe by ground beef weight, with fractions, unit conversion, and a prep checklist. Single-file web app.

🌐 Live: https://shawnrodis.github.io/Lumpiacraft/

## Features

- Scale every ingredient from the meat weight you have (lbs, kg, or grams), with quick presets and a slider
- Fractions or decimals, toggleable
- Prep checklist with progress tracking
- Dark mode (light is the default; your choice is remembered on the device)
- Philippine flag in the header and as the app icon 🇵🇭
